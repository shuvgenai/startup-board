# Startup Board: Claude app skill download

This folder holds **`startup-board.zip`**, the ready-to-upload version of Startup Board for the Claude app (web and desktop). It contains every skill file: `SKILL.md` and the 13 reference guides.

## Install in 4 steps

1. **[Download startup-board.zip](https://github.com/shuvgenai/startup-board/raw/main/startup-board-claude-skill/startup-board.zip)**. Don't unzip it.
2. In Claude, open **Settings → Capabilities → Skills**.
3. Click **Upload skill** and choose `startup-board.zip`.
4. Make sure the skill is switched on.

Then start a new chat and describe your startup idea. Startup Board starts on its own.

## Using Claude Code instead?

Install it as a plugin. See [Install](../README.md#install) in the main README.
