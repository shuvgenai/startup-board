# Customer Interview Question Bank (Mom Test-compliant)

If the `mom-test-interviews` skill is enabled, prefer it for anything interview-specific (question writing, transcript analysis, outreach). This file is a fast fallback/summary for use inside the board flow.

## Rules before writing questions for any idea
1. Ask about past/current behavior, never hypothetical future behavior ("what did you do" not "would you use").
2. Never pitch the solution during the discovery conversation.
3. Never ask for opinions or compliments ("do you like this idea") — ask for facts and specifics.
4. Anchor every question in something concrete: a recent instance, a workaround, a dollar amount, a time spent.

## Template structure (customize per idea, don't reuse verbatim)

**Opening — anchor to a real recent instance**
- "Walk me through the last time [problem context] happened."
- "What did you do about it?"

**Current workaround / cost**
- "What are you using today to deal with this — a tool, a spreadsheet, a person, or just living with it?"
- "How much time/money does that workaround cost you, roughly?"
- "What don't you like about the current way you handle this?"

**Severity / prioritization**
- "Where does this rank against the other things you're dealing with right now?"
- "Have you looked for a better solution before? What did you try, and why didn't it stick?"

**Commitment / next-step signal (only near the end, only if it's going well)**
- "Would you be open to a follow-up call once we have something to show?" (a real ask, not a hypothetical)
- "Is there anyone else dealing with this you'd suggest I talk to?"

## Red flags to strip out before sending a question list
- Any question starting with "Would you..." about the future.
- Any question that invites a compliment ("What do you think of this idea?").
- Leading questions that hint at the desired answer.

## Output format
Produce 8–12 tailored questions grouped under the four headers above, specific to the founder's actual problem and audience (pull from Phase 0 intake) — not the generic template phrasing verbatim.
