# startup-board

One AI advisor, eight startup frameworks. A Claude Code plugin that takes a founder from a raw idea to a validated plan — and, if the idea holds up, on to a build blueprint, launch plan, and pitch.

## What it does

You talk to **one advisor** who asks one question at a time and waits for your answer. Behind the scenes, it reasons like a board of eight startup experts, but you never have to deal with "a board" — just a sharp, focused conversation.

**Validation (every session)**

0. **Intake:** what you're building and for whom
1. **Interrogation:** pressure-tests the problem, customer, and assumptions
2. **Fit assessment:** problem/solution and market fit check
3. **Research:** market and industry research
4. **Documents:** Lean Canvas and interview questions
5. **Verdict:** proceed, pivot, or rethink

**Next steps (once the idea passes, or when you ask)**

6. **Build blueprint:** an MVP plan using no-code / prompt-first tools
7. **Go-to-market & launch:** a launch plan
8. **Naming, branding & pitch:** name ideas, brand direction, pitch and fundraising materials

## The eight frameworks

| Framework | Author |
|---|---|
| Business Model Canvas | Alexander Osterwalder |
| Lean Canvas (Running Lean) | Ash Maurya |
| The Mom Test | Rob Fitzpatrick |
| Lean Customer Development | Cindy Alvarez |
| Talking to Humans | Giff Constable |
| Lean Analytics | Alistair Croll & Benjamin Yoskovitz |
| AARRR (Pirate Metrics) | Dave McClure |
| Jobs-to-be-Done | Clayton Christensen |

## Install

In Claude Code, run:

```
/plugin marketplace add shuvgenai/startup-board
/plugin install startup-board@startup-board
```

Or from a terminal:

```
claude plugin marketplace add shuvgenai/startup-board
claude plugin install startup-board@startup-board
```

Then restart Claude Code.

## Use it

Just describe your idea — for example:

> I want to validate an idea for an app that helps freelancers chase late invoices.

It also starts when you ask to pressure-test an MVP, build a Lean Canvas, write customer interview questions, plan a launch, name a product, or build a pitch deck.
